# VolonterUA — V2 Scope (Backend)

## 🎯 Goal
Upgrade MVP (V1) to a production-ready platform with communication, trust, and scalability.

---

## 1. 💬 Chat System
### Tables:
- chats
- messages
- chat_participants


### Features:
- Auto-create chat on offer or accept
- WebSocket messaging
- Optional Redis for online status

### Endpoints:
- GET /chats
- GET /chats/{id}
- POST /messages

---

## 2. ⭐ Reviews & Rating
### Table:
- reviews

### Fields:
- reviewer_id
- target_user_id
- request_id
- rating (1–5)
- comment

### Rules:
- Only after request is FULFILLED

### Endpoints:
- POST /reviews
- GET /users/{id}/reviews

---

## 3. 🖼 Request Images
### Table:
- request_images

### Fields:
- request_id
- image_url

### Storage:
- S3 / Cloudinary / local (dev)

### Endpoints:
- POST /requests/{id}/images
- DELETE /images/{id}

---

## 4. 📍 Geolocation
### Add to requests:
- latitude
- longitude

### Features:
- Search by distance

### Endpoint:
- GET /requests?near=lat,lng&radius=km

## 5. 🔔 Notifications Upgrade
